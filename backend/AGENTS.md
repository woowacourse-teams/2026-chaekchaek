# 백엔드 에이전트 지침

이 파일은 `backend/` 작업의 진입점이다. 아래 경로는 이 파일이 있는 디렉터리를 기준으로 한다. 링크만 확인하지 말고 작업에 해당하는 문서를 읽는다.

| 작업 | 먼저 읽을 문서 | 적용 범위 |
| --- | --- | --- |
| 코드 작성, 수정, 테스트, 커밋, 이슈와 PR 작성 | [개발 지침](docs/ai/development-guide.md) | 설계, 컨벤션, 검증, Git 작업 절차 |

개발 지침의 우선 적용 규칙과 명시된 예외를 함께 따른다. 사용자의 명시적인 요청 없이 개발 지침을 변경하지 않는다.
