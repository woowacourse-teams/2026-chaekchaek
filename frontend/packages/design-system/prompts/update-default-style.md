Figma 디자인을 참고하여 기존 컴포넌트의 기본 스타일을 수정해 줘

## 작업 대상

- 컴포넌트: 컴포넌트_이름
- Figma: [Figma 링크]

## 작업 요청

- frontend/packages/design-system/AGENTS.md에 정의된 작업 원칙을 따라줘.
- 기본 스타일이란 컴포넌트 호출 시 Props를 생략했을 때 적용되는 스타일을 의미한다. 컴포넌트 내부에서 정의한 Props 기본값을 기준으로 판단한다.
- 기본(default) Props 조합에 해당하는 스타일만 수정한다.
- 다른 variant나 size는 별도로 수정하지 않는다. 단, 공통 스타일 변경에 따른 영향은 허용한다.

## Storybook (필요한 경우에만 포함)
- 변경된 디자인을 확인할 수 있도록 기존 Storybook도 수정해 줘.
