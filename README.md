# 책췍 - 참새도 1년에 책 두권은 읽는다

### 책 한 권으로, 주변 사람들의 생각을 만나보세요!

책췍은 책을 매개로 주변 사람들의 익명 감상을 만나고, 나의 생각을 기록하는 독서 플랫폼입니다.
읽은 책을 서재에 꽂고, 별점과 감상을 남기며 나만의 독서 기록을 쌓아보세요.

**가볍게 읽고, 솔직하게 남기는 독서 기록 서비스**, 책췍이 여러분의 1년 두 권을 응원합니다.

👉 [Google Play에서 다운로드](https://play.google.com/store/apps/details?id=com.chamsae.chaekchaek&hl=ko)

***한 권씩 꽂히는 독서 기록!***

읽은 책은 실제 책등 이미지로 서재에 꽂혀요.
별점을 매기면 같은 별점을 준 책과 비교해볼 수도 있어요.

다른 사람의 공개 서재를 구경하며
새로운 책을 발견해보세요.
