# 스프린트 1 안드로이드 요구사항: Play Store 정식 출시

- 팀: 책췍
- 선택한 요구사항: Play Store 정식 출시
- 작성 및 Console 확인일: 2026-10-08
- 상태: 프로덕션 출시 완료. 기존 개인 개발자 계정으로 비공개 테스트 12명·14일 의무 대상에 해당하지 않음

## 요구사항과 인정 기준

[LMS 스프린트 1 안드로이드 요구사항](https://techcourse-lms-plus-web.woowahan.com/missions/44?step=364)을 기준으로 작성했다. LMS에는 비공개 테스트 14일과 12명 충족 후 정식 출시가 인정 기준으로 안내되어 있다.

책췍을 출시한 개인 Google Play Console 계정은 2023-11-13 이전에 생성된 계정이다. [Google Play 공식 정책](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko)에 따르면 12명 연속 14일 비공개 테스트 의무는 2023-11-13 이후 생성된 개인 계정에 적용된다. 따라서 책췍의 정식 출시에는 해당 비공개 테스트가 필요하지 않았으며, 이 절차 없이 프로덕션 심사와 출시를 완료했다.

공통 완료 조건은 선택한 요구사항의 인정 기준 충족, 팀에 필요한 이유와 기대 변화 기록, 실제 앱 적용, 적용 전후 비교다. 이 문서에서는 출시 상태의 변화와 그 근거를 비교한다.

## 왜 지금 정식 출시가 필요한가

책췍은 책을 매개로 주변 사람들의 익명 감상을 만나고 자신의 생각을 기록하는 독서 플랫폼이다. Android 사용자가 서비스를 이용하려면 실제 앱에 접근할 수 있는 배포 경로가 필요하다.

기존 기록에서는 프로덕션 심사와 실제 게시가 분리되어 있었다. 서명된 배포 파일을 만들고 심사를 통과하더라도 관리형 게시 대기 상태라면 사용자에게 공개된 결과를 입증할 수 없다. 이번 작업의 목적은 Google Play를 통한 설치 경로를 확보하고, 배포 준비에서 실제 출시로 이어지는 과정을 완료하는 것이다.

기대 변화는 Android 사용자가 스토어 링크에서 앱을 찾아 설치할 수 있게 되는 것이다. 사용자 수나 리텐션 향상은 이 문서의 출시 확인만으로 판단하지 않는다.

## 무엇을 어떻게 적용했는가

### 기존 배포 준비와 기록

[Android 빌드 및 서명 문서](../android-build-signing.md)에 release AAB 생성, 업로드 키를 통한 서명, Play App Signing, 테스트 트랙 확인과 프로덕션 승격 절차가 정리되어 있다.

[Android 릴리스 관리 문서](../android-release-management.md)에는 서명 AAB 생성, 서명과 manifest 검증, 버전별 변경과 해시가 기록되어 있다. 이 기록은 당시 배포 준비 근거이며, 현재 공개된 빌드와 동일한 파일이라는 증거로 사용하지 않는다.

### 정식 출시 결과

최근 Play Store 배포를 완료했다는 담당자의 설명을 바탕으로 공개 스토어 페이지를 확인했다. 2026-10-01 Google Play에서 앱 상세 페이지와 설치 버튼, 버전 정보를 확인했다.

| 항목 | 확인한 내용 | 근거 |
| --- | --- | --- |
| 앱 이름 | 책췍 - 참새도 1년에 책 두권은 읽는다 | 스토어 앱 상세 페이지 |
| 패키지 ID | `com.chamsae.chaekchaek` | 스토어 URL과 앱의 `applicationId` |
| 설치 경로 | Google Play 앱 상세 페이지에 설치 버튼 표시 | [Google Play](https://play.google.com/store/apps/details?id=com.chamsae.chaekchaek&hl=ko&gl=KR) |
| 스토어 표시 버전 | `1.1.0` | 앱 정보 상세 화면 |
| 스토어 표시 업데이트 날짜 | 2026-08-31 | 앱 정보 상세 화면 |
| 스토어 표시 출시일 | 2026-08-03 | 앱 정보 상세 화면 |
| 프로덕션 출시 | `7 (1.2.1)` | 2026-10-08 Play Console 테스트 및 출시 화면 |
| 프로덕션 출시율 | 100% | 2026-10-08 Play Console 테스트 및 출시 화면 |
| 이번 프로덕션 게시 시각 | 2026-10-03 오전 10:49 | 2026-10-08 Play Console 테스트 및 출시 화면 |
| 공개 빌드의 `versionCode` | `7` | 2026-10-08 Play Console 테스트 및 출시 화면 |

스토어의 출시일과 업데이트 날짜는 이번 프로덕션 게시일을 확정하는 근거로 사용하지 않는다. 프로덕션 트랙의 `7 (1.2.1)`과 출시율 100%는 Play Console에서 별도로 확인했다. 현재 저장소와 공개 빌드의 동일성은 이 문서의 근거로 사용하지 않는다.

## 적용 전후 비교

| 비교 대상 | 이전 기록 | 현재 확인 결과 |
| --- | --- | --- |
| 배포 상태 | 2026-08-28 기록: `1.0 (2)` 심사 통과, 관리형 게시 대기, 실제 게시하지 않음 | 2026-10-08 Play Console에서 프로덕션 `7 (1.2.1)`의 출시율 100% 확인, Google Play 스토어에서 설치 버튼 확인 |
| 사용자 접근 경로 | 이전 문서에는 정식 게시 완료 근거가 없음 | Google Play 앱 상세 페이지로 직접 접근 가능 |
| 배포 버전 식별 | 이전 기록의 `1.0 (2)`와 이후 AAB 준비 기록 | 프로덕션 `7 (1.2.1)`, `versionCode` 7, 2026-10-03 오전 10:49 게시 확인 |

현재 확인한 변화는 스토어에 앱과 설치 경로가 표시된다는 것이다. 스토어에서 실제 기기로 설치한 결과와 책 검색, 서재 등록 등 앱 내부 흐름은 이번 문서 작성 과정에서 검증하지 않았다.

## 인정 기준별 증빙 상태

| 기준 | 적용 여부와 수행 결과 | 근거 |
| --- | --- | --- |
| 비공개 테스트 14일 | 필요하지 않았음. 2023-11-13 이전에 생성한 개인 계정으로 의무 대상에 해당하지 않음 | Google Play 공식 정책과 계정 소유자의 생성 시점 확인 |
| 비공개 테스트 12명 | 필요하지 않았음. 2023-11-13 이전에 생성한 개인 계정으로 의무 대상에 해당하지 않음 | Google Play 공식 정책과 계정 소유자의 생성 시점 확인 |
| 정식 출시 | 해당 계정에 필요한 프로덕션 심사와 출시 완료 | Play Console 프로덕션 `7 (1.2.1)`, 출시율 100% |
| 실제 앱에 적용 | 프로덕션 `7 (1.2.1)`, 출시율 100%, 실제 앱 패키지의 스토어 페이지 | Play Console과 Google Play 앱 상세 페이지 |
| 필요성과 전후 비교 기록 | 출시 필요성과 배포 전후 상태 기록 | 이 문서의 선택 이유와 적용 전후 비교 |

이전 문서의 비공개 테스트 근거 미확보 표기는 계정 생성 시점에 따른 정책 적용 범위를 반영하지 못한 설명이었다. 해당 테스트는 정식 출시를 위해 필요하지 않았으며, 프로덕션 정식 출시는 완료했다.
