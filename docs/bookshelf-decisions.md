# 서재·책장과 책 상세 질문 확정 사항

## 근거와 적용 범위

- 결정 근거: 2026-10-23 이 대화에 사용자가 붙여넣은 Notion 논의 내용과 후속 1-7번 확정 답변, 서재 이동 불가 사유 안내 요청.
- 문서화일: 2026-10-26. Notion 원문을 직접 조회하거나 수정한 기록은 아니다.
- 이 문서는 제품 정책과 요구사항을 기록한다. 앱 코드, 서버/API, Figma 반영과 Android/iOS 실행·배포 완료를 뜻하지 않는다. 현재 구현 여부는 이번 문서 작업에서 재검증하지 않았다.
- 이전 책장 A안과 온보딩·바로 담기 문서가 아래 결정과 충돌하면 이 문서의 결정을 우선한다. 충돌하지 않는 기존 A안 동작은 유지한다.

## 서재와 책장 구조

- 서재 안에 여러 책장이 있고, 책은 책장(`library`)에 담긴다.
- 기존의 평면 서재 구조를 여러 책장 구조로 전환한다.
- 회원가입 시 기본 책장 이름을 닉네임 그대로 설정한다. `의 책장` 또는 `의 서재` 접미어를 붙이지 않는다. 2026-10-23 이 대화의 후속 합의로 앞선 이름 정책을 대체한다.
- 닉네임은 1~10자이며 한글·영문·숫자·`-`·`_`를 허용한다.
- 기존 사용자도 백엔드에서 같은 방식으로 기본 책장을 만들고 기존 책을 옮긴다. 이번 전환에서는 일부 사용자 불편을 감수한다.
- 서재를 내가 쓴 감상·답글까지 모두 모으는 개인화 공간으로 확장하는 제안은 이번 확정 범위에 포함하지 않는다.

## 책 담기와 온보딩

- 일반 담기는 `담기 → 최근 담은 책장 자동 선택 → 필요하면 다른 책장 선택 → 확정` 순서다. 최근 담은 책장은 선택 화면에서 체크되어 있다.
- 에이블리·유튜브·스포티파이의 흐름을 참고한다. 이 문서는 해당 서비스의 현재 동작을 검증한 자료가 아니다.
- 온보딩은 현재 흐름을 유지하며 선택한 책의 저장 대상만 기본 책장으로 바꾼다. 일반 담기의 책장 선택 단계를 온보딩에 추가하지 않는다.
- 같은 책을 여러 책장에 담을 수 있다. 같은 책장 안에는 동일한 책을 중복해서 담을 수 없다.
- 책장 하나에 담을 수 있는 최대 책 수는 30권이다. 30은 책장 이름의 글자 수가 아니다.
- 임시 책장을 거치는 담기 방식은 폐기한다.
- 비로그인 사용자가 책을 담으려 하면 로그인이 필요하다고 안내한다. 안내 문구 초안: `책을 담으려면 로그인이 필요해요.`

## 이름과 순서

- 같은 사용자의 책장끼리는 이름이 중복될 수 없다. 서로 다른 사용자는 같은 책장 이름을 사용할 수 있다.
- 사용자가 설정한 책장 순서와 책장 안의 책 순서는 다른 사람이 서재를 조회할 때와 이미지 공유에도 유지한다. 로컬에서만 보이는 순서로 처리하지 않는다.
- 책장 이름의 최대 길이와 책장 수 제한은 아직 확정되지 않았다.

## 공개와 이미지 공유

- 책장은 모두 공개로 설정한다. 공개·비공개 책장을 나누는 기능은 이번 확정 범위에 포함하지 않는다.
- 공유는 링크 대신 이미지로 제공한다. 기존 A안의 단일 책장 선택은 유지하며 여러 책장을 합쳐 공유하지 않는다.
- 링크 공개 범위, 공개 데이터, 스포일러 감상 선택, 수정 반영, 수명, 취소, 재공유, 삭제·탈퇴 후 링크 처리 논의는 링크 공유 폐기에 따라 현재 범위에서 제외한다.
- 책장 상세에서 감상이 없는 책의 감상 영역은 플레이스홀더로 비워둔다. 임의의 감상이나 예시 감상을 실제 감상처럼 채우지 않는다.
- 과거 공유 페이지의 하단 스토어 버튼과 `페이지 공유` 버튼은 현재 요구사항으로 이어받지 않는다. 해당 페이지의 시안과 노드 기록은 과거 참고 자료다.

## 다른 사람 서재 구경하기

작성자 상태에 따라 서재 이동을 판단한다. 열람자의 비로그인 상태와 작성자의 비회원·익명 상태를 혼동하지 않는다. 비로그인 사용자의 책 담기 로그인 안내는 이 접근 정책과 별개의 요구사항이다.

| 작성자 상태 | 서재 이동 | 표시와 처리 | 이동 불가 사유 문구 초안 |
| --- | --- | --- | --- |
| 비익명 회원 | 가능 | 해당 회원의 서재 열기 | 해당 없음 |
| 익명으로 작성한 회원 | 불가 | 익명 이름·기본 이미지 표시, 서재 이동 차단과 사유 안내 | 익명으로 작성한 사용자의 서재는 볼 수 없어요. |
| 비회원 | 불가 | 작성자 표시, 서재 이동 차단과 사유 안내 | 비회원으로 작성한 사용자는 서재가 없어요. |
| 탈퇴 회원 | 불가 | 탈퇴 사용자 표시, 서재 이동 차단과 사유 안내 | 탈퇴한 사용자의 서재는 볼 수 없어요. |

이동 불가 사유를 설명하는 동작은 확정이다. 위 문구는 대화에서 정리한 안내 초안이며 안내를 띄우는 구체적인 UI는 이 문서에서 새로 결정하지 않는다.

## 책 상세 질문 이모지

- 질문 이모지 답변에서 별 항목을 삭제한다.
- 남는 항목은 `good`, `heart`, `think`, `calm`, `sad`의 5종이다.
- 각 항목의 표시 이름과 의미는 추가 정의가 필요하다. 확정되지 않은 의미를 임의로 부여하지 않는다.
- 이 결정은 질문의 이모지 반응에 적용한다. 개인 서재의 별점이나 감상 모달의 별점 삭제를 뜻하지 않는다.

## 저장 실패와 남은 사항

- 저장 실패는 로컬에서 처리한다는 기존 합의를 유지한다. 구체적인 실패 처리·복구 방식은 이번 논의에서 다루지 않는다.
- 이번 결정으로 이미 합의한 중복 담기, 공개 여부, 감상 없는 책의 표시와 공유 방식은 미결 항목으로 다시 분류하지 않는다.
- 기존 A안에서 미결이었던 책장에서 빼기와 기존 기록 삭제의 관계, 책장 삭제 시 독서 기록·감상 보존은 이번 대화에서도 확정되지 않았다.
