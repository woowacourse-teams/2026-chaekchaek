# 책등 이미지 활용 메모

## 목적과 요약

피드나 서재에서 표지 대신 책등 이미지를 검토할 때 재사용할 프로젝트 지식이다.
현재 확인한 방식은 별도 백엔드 API가 아니라 YES24 이미지 URL을 프론트에서 조합하는 방식이다.

- URL 형식: `https://image.yes24.com/goods/{yes24ProductId}/SIDE/XL`
- 식별자는 YES24 상품번호다. ISBN이나 우리 서비스의 책 ID를 그대로 넣으면 안 된다.
- 과거 프론트엔드에 책등 활용 테스트가 있었지만, 이를 현재 운영 기능이나 전체 도서 지원으로 간주하지 않는다.

- 커밋: [`408c5268471b36bed23f8cc033e5624aad45552e`](https://github.com/woowacourse-teams/2026-chaekchaek/commit/408c5268471b36bed23f8cc033e5624aad45552e)

- 샘플 상품번호 `195042981`의 `SIDE/XL` 주소에 HEAD 요청을 보내 HTTP 200을 확인했다. 이는 해당 샘플의 응답 확인이며, 이미지 내용·모든 도서의 제공 여부·공식 지원 계약을 검증한 것은 아니다.
- 조사 당시 fetch한 원격 브랜치의 `backend`, `frontend`에서 `spine`, `책등`을 검색했을 때는 결과가 없었다. 전체 Git 이력의 커밋 메시지를 검색해 위 구현을 발견했다. 다른 명칭의 API 존재 여부까지 부정하는 근거는 아니다.

재확인 명령:

```sh
git show 408c5268:frontend/apps/chaekchaek/src/pages/MemberLibraryPage/MemberLibraryPage.tsx
curl -I https://image.yes24.com/goods/195042981/SIDE/XL
```

## 나중에 적용할 때

1. 현재 책 응답에 YES24 상품번호 또는 해당 상품 URL이 있는지 먼저 확인한다. 없다면 ISBN과 상품번호의 연결 방법을 확인한다.
2. 실제 대상 도서와 판본에 맞는 책등 이미지인지 확인한다. HTTP 200만으로 이미지가 올바르다고 판단하지 않는다.
3. 이미지가 없으면 해당 책의 표지나 제목 기반 대체 표현을 사용한다. 과거 테스트처럼 다른 책의 이미지를 대신 보여주지 않는다.
4. 표시 비율과 글자 식별성을 실제 모바일 크기로 비교한다. 책등을 작은 표지 자리에 단순 교체하면 식별성이 더 낮아질 수 있다.
5. 운영 반영 전 외부 이미지 사용 조건과 로딩 실패 처리를 확인한다. 현재 메모는 공식 API 사양 보증이 아니다.

## 디자인 결정과 미결정

- 감상 피드는 B 구분선 SNS형, 인용은 A 따옴표형을 사용자가 선택했다.
- 작은 표지 대신 책등을 활용하는 아이디어가 제안됐다.
- 책등의 크기·배치, 실제 도서 매핑, 운영 적용은 아직 확정하거나 구현하지 않았다.
