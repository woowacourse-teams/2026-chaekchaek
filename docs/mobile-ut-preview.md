# 스프린트 4 모바일 UT 미리보기

이슈 #675, 통합 Draft PR #676의 UI 확인용 로컬 산출물이다. 2026-11-05 사용자가 Figma 구독 종료로 MCP에 연결할 수 없다고 알렸으며, 이번 작업은 Figma 검증 대신 로컬 HTML로 보여달라고 명시했다. 이 예외는 이번 모바일 UT 작업에 적용한다.

## 미리보기와 기준

- [HTML 열기](../handoff/mobile-ut-preview/index.html). 파일을 직접 열거나 해당 폴더에서 `python3 -m http.server 18765 --bind 127.0.0.1`로 실행한다.
- 기준 앱 코드는 `93f3c76b`의 공통 화면과 테마다. Gowun Dodum, Pretendard, 마스코트, 탭 벡터와 별 이미지를 기존 앱 자산에서 가져왔다.
- 책과 감상은 예시다. 저장과 제출은 페이지 메모리에서만 동작하며 API 요청, 인증과 실제 데이터 변경은 없다.
- HTML 확인은 Figma 등록, Android/iOS 코드 반영이나 실제 기기 검증을 뜻하지 않는다. 사용자가 HTML 시안을 승인했다고 아직 판단하지 않는다.

## 앱 반영과 구분

검색 중복 ISBN 제거, 출발 책장 직접 저장 ViewModel과 온보딩 등 일부 입력의 키보드 닫기는 앱에 반영되어 있다. 검색 명칭, 피드와 검색 TOP, 책장 담기에서 검색으로 이동하는 UI 연결, 별점 드래그와 감상 진입 문구는 이 HTML의 검토 대상이며 앱 반영은 남아 있다. 웹과 서버 변경은 범위 밖이다.

Android UI 트리에서 기존 Compose 테스트 태그를 안정적으로 조회하도록 Android 호스트에 리소스 ID 노출을 추가했다. 이는 기존 태그를 노출하는 변경이며 iOS의 공통 UI나 기능 의미를 바꾸지 않는다.

## 2026-11-05 검증

- Android host 테스트 495개, Debug APK와 AndroidTest APK 빌드 통과. Pixel 6a API 33에서 동일 버전 1.3.1(10), 동일 서명을 확인하고 데이터를 보존해 설치했다.
- 온보딩 화면 fixture의 실제 탭과 네이티브 키 입력으로 빈 영역 탭 후 포커스 해제, 입력칸 재진입 3회, IME 검색 후 포커스 해제와 검색어 보존 테스트 1개가 통과했다. 실제 계정과 온보딩 저장 상태를 초기화하지 않았다. 이 테스트는 포커스와 내용 보존을 검증하며 별도의 키보드 표시 상태 검사는 없다.
- Jev의 홈에서 발견 탭 이동은 1단계로 통과했다. 후속 검색 시나리오는 빈 검색창 탭 이후 앱의 MotionEvent 응답 지연 ANR로 중단됐다. `archi` 입력 전 발생했으며 제보된 검색 크래시와 같은 원인인지는 미확인이다. ANR 당시 메인 스택은 `nativePollOnce`였고 원인은 특정하지 못했다. 기기 데이터는 지우지 않았다.
- 기존 게스트 상태로는 책장과 닉네임 변경에 진입할 수 없어 해당 실제 계정 경로와 저장 완료는 미검증이다. iOS는 이전 `93f3c76b`의 키보드 테스트 근거를 유지하며 이번 Android 전용 태그 노출과 HTML 작업으로 새 실행을 주장하지 않는다.
- HTML 390px, 320px에서 화면을 확인했다. 출발 책장 직접 담기 왕복, 중복 없는 제목 검색 결과, 별점 포인터 드래그, 입력 포커스 해제와 내용 보존, 상세 TOP 복귀 및 가로 넘침 없음을 확인했다.
