# 레벨4 과제 제출 문서

## 요약

레벨4 프로젝트 LMS의 단계별 안내와 스프린트 1 제출 기준을 저장소 안에서 빠르게 찾기 위한 문서 모음이다. LMS 원문을 확인한 날짜는 2026-10-01이며, 마감 시각과 제출 상태는 LMS를 최종 기준으로 확인한다.

## 라우팅

| 목적 | 문서 |
| --- | --- |
| LMS 단계별 안내의 제목, 원문 경로, 핵심 내용 확인 | [LMS 단계 수집 목록](lms-page-catalog.md) |
| 스프린트 1 제출 전 제출물과 필드를 확인 | [스프린트 1 제출 기준](sprint-1-submission.md) |

## 제출 순서

1. [스프린트 1 제출 기준](sprint-1-submission.md)에서 분야별 산출물과 제출 필드를 확인한다.
2. 각 산출물의 근거 문서가 담당 코치에게 열리는지 확인한다.
3. 팀 대표가 LMS의 [스프린트 1 제출](https://techcourse-lms-plus-web.woowahan.com/missions/44?step=355) 단계에 입력한다.
4. 제출 뒤에는 수정할 수 없으므로 저장 내용과 링크를 다시 확인한다.
5. 제출만으로 완료되지 않으며, 담당 코치의 승인까지 받아야 한다.
