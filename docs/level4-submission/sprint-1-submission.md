# 스프린트 1 제출 기준

## 제출 위치와 마감

- LMS [스프린트 1 제출](https://techcourse-lms-plus-web.woowahan.com/missions/44?step=355) 단계에서 팀 대표 한 명이 제출한다.
- 기술, 제품, 소프트스킬 산출물은 한 폼에 함께 입력한다.
- LMS에 표시된 제출 마감은 2026-10-01 18:00이다.
- 저장 후 제출하면 수정할 수 없다.
- 제출 뒤 담당 코치 승인까지 받아야 완료다.

## 안드로이드 선택지와 공통 완료 조건

스프린트 1에서 다음 중 하나를 선택한다.

1. 데모 APK 배포와 정적 분석
2. 크래시와 행동 분석
3. 베타 배포, 버저닝, 난독화
4. Play Store 정식 출시
5. Compose 전환
6. DI 라이브러리 적용

선택한 항목의 인정 기준을 충족하고, 현재 팀에 필요한 이유와 기대 변화, 실제 앱 적용, 적용 전후 비교를 기록한다. 레벨3에서 수행한 항목도 레벨4 기준으로 다시 수행해야 한다.

## 제출 직전 확인

1. 팀에 없는 기술 분야는 빈칸 대신 `해당 없음`으로 입력한다.
2. 모든 문서 링크는 담당 코치가 열 수 있어야 한다.
3. 문서에는 결과뿐 아니라 수행 과정, 의사결정 근거, 관찰 결과가 있어야 한다.
4. 저장된 폼의 모든 링크와 내용을 확인한 뒤 최종 제출한다.
