# Android 정식 출시 심사 및 사용자 관찰

이 문서는 Google Play 프로덕션 심사 제출과 실제 사용자 관찰 과제의 수행 근거를 한곳에
기록한다. Play 운영 절차와 버전 이력은
[Android 버전 및 릴리스 관리](android-release-management.md)에서 별도로 관리한다.

## 완료 조건

- 프로덕션 트랙에 릴리스를 올려 심사 제출까지 완료한다.
- 배포한 앱을 실제로 쓰는 사용자를 관찰한다.
- 확인하려는 질문과 판단 기준을 관찰 전에 정한다.
- 관찰한 사실, 팀의 해석과 그에 따른 다음 행동을 구분해 기록한다.

## 프로덕션 심사 제출

확인일: 2026-08-28

| 항목 | 확인 결과 |
| --- | --- |
| 트랙 | 프로덕션 |
| 버전 | `1.0 (2)` |
| 대상 국가 | 대한민국 |
| 심사 상태 | 심사 통과, 관리형 게시 대기 |
| 타겟 연령 | 만 6-17세, 의도한 설정 |
| 실제 게시 | 하지 않음 |

Play Console 게시 개요에서 프로덕션 `1.0 (2)` 전체 출시와 대한민국 배포를 포함한 13개
변경사항이 `게시 준비됨` 상태인 것을 확인했다. 관리형 게시가 활성화되어 있어 심사 통과와 실제
게시를 분리할 수 있다. 과제 완료 조건은 심사 제출까지이므로 프로덕션 게시 버튼은 누르지 않는다.

## 사용자 관찰 계획

상태: 진행 전

- 관찰 질문: 처음 사용하는 사람이 도움 없이 책 검색부터 서재 등록까지 완료할 수 있는가?
- 대상: 사용자 3명
- 판단 기준: 3분 이내에 도움 없이 2명 이상 완료
- 방법: 사용자가 직접 앱을 조작하게 하고 진행을 돕지 않은 채 행동과 발언을 기록한다.
- 수집 항목: 익명 식별자, 관찰된 행동, 사용자 발언, 완료 여부
- 개인정보: 이름, 이메일, 영상과 그 밖의 개인 식별 정보는 저장소에 기록하지 않는다.
