## 이번 작업에서 확정한 결정 (중요)
1. 책장 생성, 이름 변경, 삭제, 책 넣기와 빼기, 책장 및 책 순서 변경을 모두 제공한다. 책장 이름을 표시한다.
2. 메인 책장 핸들을 드래그하면 책장 순서를 바꾼다. 책등을 길게 누르면 같은 책장 안의 책 순서를 바꾼다. 상세에서도 책등 재정렬이 가능하다. 책장 사이 책 이동은 확정 범위가 아니다.
3. 상세의 아래 책 목록은 책 표지를 쓰고 행마다 드래그 핸들을 둔다. 책등과 표지 목록은 같은 순서를 보여준다.
4. 삭제 편집 모드에는 삭제만 제시한다. 완료하면 일반 상태의 드래그 핸들이 돌아온다. A안의 `관리` 텍스트는 없애고 추가 버튼은 작은 + 버튼을 쓴다.
5. 메인과 상세 책등은 140% 고정이며 전역 슬라이더는 없다. 넘치는 책등은 가로 스크롤한다.
6. 이미지 저장 모달에는 배율 슬라이더를 둔다. 기존 이미지 시안은 기본 140%, 범위 100~200%, 간격 5%다. 배율에 따라 책등을 줄바꿈하며 한 책장의 책 전체를 담는다. 공유 페이지는 현재 범위에서 제외한다.
7. 이미지 저장과 이미지 공유는 책장 하나만 선택한다. 여러 책장을 합쳐 공유하지 않는다.
8. 기존 서재와 검색 양쪽에서 책을 담으며 읽음 여부로 제한하지 않는다. 일반 담기는 최근 담은 책장을 자동 선택한 뒤 필요하면 변경하고 확정한다. 온보딩은 기존 흐름대로 기본 책장에 저장한다.
9. 이미지의 책췍 표시는 우측 상단에 둔다.
10. 책장 상세에서 감상이 없는 책의 감상 영역은 플레이스홀더로 비워둔다. 과거 공유 시안의 예시 감상을 실제 데이터로 쓰지 않는다.
11. 모든 책장은 공개한다. 작성자 상태별 서재 이동 허용과 불가 사유 안내는 후속 확정 문서를 따른다.
12. 같은 책을 여러 책장에 담을 수 있으나 같은 책장 안의 중복은 불가하다. 책장당 최대 30권이며 같은 사용자의 책장 이름은 중복할 수 없다. 기본 책장 생성과 기존 사용자 이관도 후속 확정 문서를 따른다.
13. 삭제한 문구: `책으로 소개하는 나`, `좋아하는 책들을 한 장에 담아보세요.`, `좋아하는 책을 모아두었어요.`, `2개의 책장을 소개합니다` 및 같은 형태의 동적 안내.
14. 성공 기준은 사용자가 자신이 고른 책장을 실제 이미지로 공유하는 것이다. 시안 확인 기준은 큰 책장 모습과 편집 및 공유 흐름 확인이다.

## 다음에 할 일 (구현 단계)
1. 현재 소스와 최신 서버 OpenAPI를 확인해 책장 모델, 소속, 순서, 영구 저장 API의 존재와 변경 범위를 파악한다. 위 파일 경로는 탐색 시작점이며 수정 대상을 확정한 목록이 아니다.
2. 남은 미정 사항은 책장에서 빼기와 기존 기록 삭제의 관계, 책장 삭제 시 기록 보존, 책장 이름 최대 길이와 책장 수 제한이다. 중복 담기·공개·감상 없음·이미지 공유 정책은 확정 문서를 따른다. 저장 실패의 세부 복구는 이번 논의 제외이며 링크 수명·취소 정책은 현재 범위가 아니다.
3. `chaekchaek-design-system`과 기능에 맞는 `intent-first`, `flow-first`를 적용한다. Figma 대상 화면, 공통 컴포넌트와 레퍼런스를 실제 조회한 뒤 미정 로딩, 오류와 데이터 없음 상태를 확인한다. 원본 불일치는 코드 구현 전에 해결한다.
4. 승인된 범위에 맞춰 책장 목록, 상세, 편집과 담기를 Android와 iOS에 함께 구현한다. 책등과 표지 목록의 동일 순서, 재정렬과 스크롤 구분, 왕복 시 입력과 순서 보존, 저장 실패 후 복구를 검증한다.
5. 이미지 저장과 OS 이미지 공유를 플랫폼별로 연결하고 미리보기와 실제 파일이 일치하는지 확인한다. 공개 페이지나 링크를 생성하는 작업은 제외한다. 샘플 감상과 시안 안내를 운영 기능으로 간주하지 않는다.
6. 두 플랫폼에서 생성, 이름 변경, 삭제 취소와 확정, 기존 서재 및 검색 담기, 책 빼기, 책장/책 재정렬, 이미지 저장, 단일 책장 이미지 공유를 실행한다. 최근 책장 선택, 기본 책장 온보딩 저장, 책장 간 동일 책 담기·같은 책장 중복 차단, 최대 30권과 서재 이동 불가 안내도 확인한다. 빌드, 자동 테스트, 실제 기기 흐름, 배포 증거를 구분해 기록한다.
